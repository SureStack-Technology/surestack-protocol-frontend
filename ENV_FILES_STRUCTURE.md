# SureStack Protocol - Environment Files Structure

## 📁 Complete .env File Paths and Purposes

This document maps all environment variable files in the SureStack Protocol project.

---

## 🎯 Primary Environment Files

### 1. **Root `.env`** (Hardhat/Deployment)
**Path:** `/SureStack/.env`  
**Status:** ✅ **EXISTS** (gitignored)  
**Purpose:** Hardhat deployment and contract interaction  
**Used by:**
- `hardhat.config.js` (for network configuration)
- Deployment scripts (`scripts/deploy.js`, `scripts/deploy-sepolia-and-configure.js`)
- Hardhat scripts (`scripts/fix-oracle-reader.js`)

**Required Variables:**
```env
# Wallet & Network
PRIVATE_KEY=your_private_key_here
INFURA_API_URL=https://sepolia.infura.io/v3/YOUR_INFURA_PROJECT_ID
# OR
RPC_URL=https://sepolia.infura.io/v3/YOUR_INFURA_PROJECT_ID

# Optional
ETHERSCAN_API_KEY=your_etherscan_key
CHAINLINK_ORACLE_ADDRESS=0x694AA1769357215DE4FAC081bf1f309aDC325306

# Contract Addresses (auto-populated by deployment scripts)
SURESTACK_TOKEN_ADDRESS=0x...
CONSENSUS_STAKING_ADDRESS=0x...
REWARD_POOL_ADDRESS=0x...
DAO_GOVERNANCE_ADDRESS=0x...
ORACLE_CONTRACT_ADDRESS=0x...
POLICY_MANAGER_ADDRESS=0x...
```

**Template:** `env.template` (root directory)

---

### 2. **Backend `.env`** (Express API Server)
**Path:** `/SureStack/backend/.env`  
**Status:** ✅ **EXISTS** (gitignored)  
**Purpose:** Backend Express.js API server configuration  
**Used by:**
- `backend/src/server.js`
- `backend/src/config/blockchain.js`
- `backend/src/config/contracts.js`
- `sync-env.js` (reads from here to sync to frontend)
- `scripts/fix-oracle-reader.js` (reads from here)

**Required Variables:**
```env
# Server Configuration
PORT=5000
NODE_ENV=development

# Blockchain Configuration
INFURA_API_URL=https://sepolia.infura.io/v3/YOUR_INFURA_PROJECT_ID
# OR
RPC_URL=https://sepolia.infura.io/v3/YOUR_INFURA_PROJECT_ID

# Optional: For write operations
PRIVATE_KEY=your_private_key_here

# Contract Addresses
SURESTACK_TOKEN_ADDRESS=0x...
CONSENSUS_STAKING_ADDRESS=0x...
REWARD_POOL_ADDRESS=0x...
DAO_GOVERNANCE_ADDRESS=0x...
ORACLE_CONTRACT_ADDRESS=0x...
POLICY_MANAGER_ADDRESS=0x...

# Chainlink Oracle (Sepolia ETH/USD)
CHAINLINK_ORACLE_ADDRESS=0x694AA1769357215DE4FAC081bf1f309aDC325306

# CORS Configuration
ALLOWED_ORIGINS=http://localhost:3000,http://localhost:3001
```

**Template:** `backend/ENV_EXAMPLE.txt`

**Fallback Keys (for backward compatibility):**
- `RISK_TOKEN_CONTRACT` → `SURESTACK_TOKEN_ADDRESS`
- `CONSENSUS_CONTRACT` → `CONSENSUS_STAKING_ADDRESS`
- `REWARD_POOL_CONTRACT` → `REWARD_POOL_ADDRESS`
- `DAO_CONTRACT` → `DAO_GOVERNANCE_ADDRESS`
- `ORACLE_INTEGRATION_CONTRACT` → `ORACLE_CONTRACT_ADDRESS`

---

### 3. **Frontend `.env.local`** (Vite React App)
**Path:** `/SureStack/.env.local`  
**Status:** ✅ **EXISTS** (gitignored, auto-generated by `sync-env.js`)  
**Purpose:** Frontend Vite React application environment variables  
**Used by:**
- `src/config/contracts.js` (reads VITE_* variables)
- `src/contexts/Web3Context.jsx` (network configuration)
- `src/hooks/useContracts.js` (contract addresses)

**Required Variables:**
```env
# Sepolia RPC (optional - defaults to public RPC)
VITE_SEPOLIA_RPC=https://sepolia.infura.io/v3/YOUR_INFURA_PROJECT_ID
# OR use public: https://rpc.sepolia.org

# Contract Addresses (must be VITE_ prefixed for Vite to expose them)
VITE_ORACLE_READER_V2_ADDRESS=0x...
VITE_POLICY_MANAGER_ADDRESS=0x...
VITE_REWARD_POOL_ADDRESS=0x...
VITE_CONSENSUS_STAKING_V2_ADDRESS=0x...
VITE_DAO_GOVERNANCE_ADDRESS=0x...
VITE_SURE_STACK_TOKEN_ADDRESS=0x...
```

**How it's created:**
- Automatically synced from `backend/.env` using `sync-env.js`
- Run: `npm run sync:env` or `node sync-env.js`

**Note:** Vite only exposes variables prefixed with `VITE_` to the client-side code.

## 🔄 Environment Variable Flow

```
┌─────────────────────────────────────────────────────────────┐
│                    DEPLOYMENT FLOW                           │
└─────────────────────────────────────────────────────────────┘

1. Root .env (Hardhat)
   ├─ PRIVATE_KEY
   ├─ INFURA_API_URL
   └─ Contract addresses (after deployment)
      │
      └─→ Written by deployment scripts
          └─→ deployment-info.json

2. Backend .env (Express API)
   ├─ Reads from root .env (manually or via scripts)
   ├─ INFURA_API_URL / RPC_URL
   ├─ PRIVATE_KEY (optional)
   └─ Contract addresses
      │
      └─→ Used by backend/src/config/contracts.js

3. Frontend .env.local (Vite React)
   ├─ Auto-synced from backend/.env via sync-env.js
   ├─ VITE_SEPOLIA_RPC
   └─ VITE_* contract addresses
      │
      └─→ Used by src/config/contracts.js
```

## 🛠️ Scripts That Use Environment Files

### `sync-env.js` (Root)
**Reads from:** `backend/.env`  
**Writes to:** `.env.local` (root)  
**Purpose:** Syncs contract addresses from backend to frontend  
**Usage:** `npm run sync:env`

**Mapping:**
- `INFURA_API_URL` or `RPC_URL` → `VITE_SEPOLIA_RPC`
- `SURESTACK_TOKEN_ADDRESS` or `RISK_TOKEN_CONTRACT` → `VITE_SURE_STACK_TOKEN_ADDRESS`
- `CONSENSUS_STAKING_ADDRESS` or `CONSENSUS_CONTRACT` → `VITE_CONSENSUS_STAKING_V2_ADDRESS`
- `REWARD_POOL_ADDRESS` or `REWARD_POOL_CONTRACT` → `VITE_REWARD_POOL_ADDRESS`
- `DAO_GOVERNANCE_ADDRESS` or `DAO_CONTRACT` → `VITE_DAO_GOVERNANCE_ADDRESS`
- `ORACLE_CONTRACT_ADDRESS` or `ORACLE_INTEGRATION_CONTRACT` → `VITE_ORACLE_READER_V2_ADDRESS`
- `POLICY_MANAGER_ADDRESS` → `VITE_POLICY_MANAGER_ADDRESS`

### `scripts/fix-oracle-reader.js` (Hardhat Script)
**Reads from:** `backend/.env`  
**Purpose:** Verifies and configures OracleReaderV2 contract  
**Usage:** `npm run fix:oracle`

**Required Variables:**
- `INFURA_API_URL` or `RPC_URL`
- `PRIVATE_KEY`
- `ORACLE_CONTRACT_ADDRESS` or `ORACLE_INTEGRATION_CONTRACT`
- `CHAINLINK_ORACLE_ADDRESS` (optional, defaults to Sepolia ETH/USD)

## 📝 Setup Instructions

### Step 1: Create Root `.env`
```bash
# Copy template
cp env.template .env

# Edit with your values
nano .env
```

### Step 2: Create Backend `.env`
```bash
# Copy example
cp backend/ENV_EXAMPLE.txt backend/.env

# Edit with your values
nano backend/.env
```

### Step 3: Sync to Frontend
```bash
# Auto-sync from backend/.env to .env.local
npm run sync:env
```

---

## ⚠️ Important Notes

1. **All `.env` files are gitignored** - Never commit them to git
2. **Vite requires `VITE_` prefix** - Only variables with this prefix are exposed to frontend
3. **Backend uses fallback keys** - Supports both new and legacy variable names
4. **Hardhat reads from root `.env`** - For deployment and scripts
5. **Backend reads from `backend/.env`** - For API server
6. **Frontend reads from `.env.local`** - For Vite React app

## 📞 Troubleshooting

### Frontend shows "Missing Environment Variables"
- Run `npm run sync:env` to sync from backend
- Check that `backend/.env` has all contract addresses
- Verify `.env.local` exists in root directory

### Backend can't connect to contracts
- Check `backend/.env` has correct contract addresses
- Verify `INFURA_API_URL` or `RPC_URL` is set
- Check network matches (Sepolia)

### Hardhat scripts fail
- Check root `.env` has `PRIVATE_KEY` and `INFURA_API_URL`
- Verify contract addresses are set
- Check network configuration in `hardhat.config.js`
